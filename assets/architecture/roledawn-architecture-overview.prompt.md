# RoleDawn architecture overview image prompt

Generation mode: built-in image generation, `infographic-diagram`.

Create a premium landscape architecture poster for RoleDawn. Use an original
tactile 2.5D editorial style with matte paper, precise rails, restrained soft
shadows, and smooth geometric sans-serif typography. Use RoleDawn's Midnight,
Cloud, Dawn Coral, First Light, Signal Mint, and Slate palette.

The composition must be architecturally exact:

- two independent upper chambers, `01 CANDIDATE INTELLIGENCE` and
  `02 OPPORTUNITY INTELLIGENCE`;
- the candidate enters only Candidate Intelligence;
- official job sources enter only Opportunity Intelligence;
- each chamber emits a sealed snapshot;
- both snapshot rails converge into a large third chamber,
  `03 APPLICATION DELIVERY`;
- Application Delivery assembles one Application Kit, then passes through
  candidate approval, a temporary browser, the employer ATS, and finally an
  evidence-backed receipt;
- one `SHARED CONTROL PLANE` foundation supports all three chambers.

Candidate Intelligence and Opportunity Intelligence must never point into one
another. Approval must appear before the browser. The browser must look
temporary per attempt. The receipt must come only after the employer ATS.
Models may appear only as small drafting tools, never as authority.

Avoid a serial `01 → 02 → 03` flow, generic SaaS boxes, tiny dense text, robot
mascots, briefcases, floating orbs, glassmorphism, galaxies, neon AI gradients,
company logos, fake metrics, autonomy claims, and watermarks.
